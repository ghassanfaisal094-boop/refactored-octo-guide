NUC Security Engine

Three locks.
One device.
Zero exceptions.

Copy the file to a new machine — it dies. Change the hardware — it dies. Vendor marks revoked — it dies on next open. This is not VBA password protection. This is device-level binding.

🛡️
Instant Violation Detection
When a mismatch is detected, the workbook locks all sheets, hides all tabs, disables every button and keyboard shortcut, and sends you an email alert — all before the user sees anything.
📡
Remote Kill Switch
Change one cell in your Google Sheet to REVOKED. Next time the client opens the file — disabled. No physical access required. Works from anywhere.
🔄
Device Transfer Support
When clients reinstall Windows or change hardware, you run VendorTransfer, enter new device data, re-send the file. Clean process, full audit trail, no license wasted.
📶
Offline Grace Period
3-day offline tolerance backed by local fingerprint verification. Clients in low-connectivity environments keep working — but the server gets updated the moment they reconnect.

Setup Process

From purchase to production
in 4 steps.

No installation. No IT team. No server infrastructure on the client side. Just a file that knows exactly which machine it belongs to.

01
📋
Client Sends Device Data
Client opens the workbook. The system reads PC Name, MAC address, and Device ID automatically — copies everything to clipboard. Client pastes and sends to vendor.
02
⚙️
Vendor Pre-Registers
Vendor runs VendorPreRegister on their copy. Enters client data. System registers the device on the Google server and embeds credentials directly into the workbook file.
03
📤
Configured File Sent
Vendor saves the now-configured workbook and sends it to the client. When client opens it, the security check passes automatically — no activation step needed.
04
📡
Live & Tracked
Every open logs to the vendor's master Google Sheet in real time. Timestamps, device names, MAC addresses. Remote kill switch always active from the vendor dashboard.
